Repository for SpeciMate software

SpeciMate is an open-source stand-alone application developed using LiveCode (version 9.6.8 and above), a cross-platform development environment that enables deployment on both Windows and macOS systems without the need to install other software libraries. The application is designed to be user-friendly and accessible to collection staff without requiring specialised technical knowledge, while providing powerful capabilities for metadata extraction and curation.

https://www.sciencedirect.com/org/science/article/pii/S1314283625001691

To install:

- Download the Windows or Mac binary and the SpeciMate-Data folders to a location on your local instance
- Run the SpeciMate Excecutable

Note the Services folder contains placeholder JSON files without API keys to the relevant services - these will need to be updated
