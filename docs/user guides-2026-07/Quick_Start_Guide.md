# Quick Start Guide
Create date: 2026-07-07
Last modified date: 2026-07-07

A simple walkthrough of the main window, top to bottom. Work through the steps in order.

## Step 1: Project Setup
Start here. Create a **New Project** (or **Open Project** to continue an existing one), point the **Image folder** field at the folder holding your images, and choose the **Select definition** type that describes what you're working with. Use **Save Project** and **Close Project** from the same row when needed.

## Step 2: Select Processes
Tick what you want done to the images:
- **OCR?** — read the text contained in the images.
- **Translate?** — translate that text.
- **Extract Entities?** — pull out specific pieces of information.

Then pick the AI model under **Select Model**. Optionally turn on **Multimodal?**, tick **Use translation?**, or **Exclude some text from entity extraction?**.

## Step 3: Prompt Details
Tell the AI how to behave:
- **Role** — sets the AI's perspective.
- **Prompt** — the instructions it should follow.
- **Columns** — the fields you want returned.

Load a saved prompt definition from the **Library**, start a **New** one, or **Edit Prompt** to change the current one.

## Step 4: Process Images
Click **Process images** to run everything you set up. The list on the left lets you **Filter**, **Show**, and view your image files. The **Progress** bars on the right track OCR, Translation, and Extract, with the **OCR result** appearing below.

## Step 5: Data Curation
Review and clean up the results using custom curation display screens. Select one from the menu or from the library.

## Step 6: Data Check and Export
Do a final check and export your finished data (for example, the **LLM data** output).

## In short
Set up the project → choose what to do → tell the AI how to do it → run it → tidy the results → export.
